# Pokédex Go

Pokédex pessoal desenvolvida com `React` e `Vite`, inspirada no universo de `Pokémon`.

O projeto foi pensado para registrar os Pokémons capturados e exibi-los em cards com identidade visual própria, suporte a tema claro e escuro e experiência responsiva para desktop e mobile.

## Funcionalidades

- cadastro manual de Pokémons
- auto preenchimento pelo número da Pokédex com dados da `PokeAPI`
- busca por nome, número ou tipo
- remoção de cards
- persistência de dados no navegador com `localStorage`
- alternância entre tema `light` e `dark`
- layout responsivo

## Tecnologias

- `React`
- `Vite`
- `ESLint`
